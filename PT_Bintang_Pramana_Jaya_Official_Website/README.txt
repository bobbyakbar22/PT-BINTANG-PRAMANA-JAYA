LANGKAH PUBLIKASI UMUM UNTUK HOSTING cPANEL:
1. Masuk ke panel hosting.
2. Buka File Manager dan cari Document Root untuk bintangpramanajaya.com (sering kali public_html, tetapi periksa pengaturan domain).
3. Unduh/cadangkan file situs lama sebelum menggantinya.
4. Unggah ZIP paket website.
5. Ekstrak di Document Root yang benar.
6. Pastikan index.html berada langsung di Document Root dan folder assets berada sejajar dengannya.
7. Pastikan DNS domain mengarah ke hosting dan aktifkan SSL/HTTPS.
8. Uji https://bintangpramanajaya.com, tampilan ponsel, logo, navigasi, dan tautan email.

Jika hosting menggunakan WordPress atau website builder, jangan menimpa file secara langsung sebelum memeriksa cara situs saat ini dibangun. Jangan pernah membagikan kata sandi atau OTP.

Website belum dipublikasikan dari sini karena akses panel hosting belum tersedia.
